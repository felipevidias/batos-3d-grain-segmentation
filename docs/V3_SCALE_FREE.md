# BA-TOS v3 (scale-free) — design record

Phase 5e. Designed on the 12 EFR dev crops and a synthetic scale test only; the 52 test crops are not read until v3 is
frozen (tag `batos-paper-v3-scalefree`). Code: `src/batos_v3/` (new); frozen v2 scripts are called unchanged, except
three generated copies (`src/batos_v3/patched/`, from `batos_v3.make_patched`) whose only change is exposing a
hard-coded constant as a CLI flag with the frozen value as default.

## 1. Scale source (step 1)

`r_granulo` = argmax of the binary pattern spectrum (exact Euclidean ball openings, r = 2..40) of the specimen-only Otsu
foreground (`batos_v3/scale.py`):

1. pass 1: robust p1–p99 → uint8, `fg0 = fill_holes(u8 > Otsu)`, `r0 = argmax PS(fg0)`;
2. specimen = `fill_holes(largest 6-component of closing(fg0, ball(2 r0)))`;
3. pass 2: robust rescale and Otsu on specimen voxels only, `fg1 = fill_holes(u8 > Otsu) ∩ specimen`,
   `r_granulo = argmax PS(fg1)`;
4. openrec radius = `max(8, round(1.5 r_granulo))`; `openrec_lowmem` (bit-identical) above radius 15.

Iteration 0 without `fill_holes` gave r = 7 on all dev crops (enclosed noise cavities cap the EDT); with it, r = 10 on
all 12 dev crops (GT inscribed radius 10.6). `fill_holes` has no parameter.

## 2. Downstream constants (step 2)

s = r_granulo / R_REF with **R_REF = 10** (= r_granulo of every dev crop), so on the dev crops s = 1 and every scaled
constant equals its v2 value. Rules: L (length) v2·s; V (volume / ToS area, voxels) v2·s³; N (objects per crop) v2/s³;
VF (voxel-degeneracy limit) v2·max(1, s³); D/Q/R kept (dimensionless, rank, or relative to the image's own robust
p0.5–p99.5 range); X removed (set to the non-binding limit); T replaced by a rule. Integer flags are rounded, ≥ 1.

**Replaced (behaviour changes at s = 1):**

| constant | before (v2) | after (v3) | why |
|---|---|---|---|
| scale | e13: median of the 1,500 highest EDT 5³-maxima | r_granulo (§1) | e13 underestimates ≈ 2× on large grains (test forensics) |
| openrec radius | max(8, round(1.5 r_e13)) | max(8, round(1.5 r_granulo)) | follows the scale |
| stage-03 dark threshold | min(Otsu(selector) − 10, p40(selector > 0), 135) | Otsu(selector on specimen voxels) | p40/135 branch percolates (test forensics); no relative guard kept — offset −10 dropped too |
| stage-03 `--center-dark-max` | 210 | removed (255) | 0 rejections in 115 dev+test runs |
| stage-03 `--min-ring-contrast` | −5 | removed (−255) | 0 rejections in 115 runs |
| stage-04 `--center-dark-max` | 205 | removed (255) | 3 rejections in 1.93 M components |
| e11 "no MIN candidate inside internal_dark" | RuntimeError (crash) | recorded empty result (F1 0) | |
| gate limits m_v ≤ 3, q_v ≤ 4 | hard-coded | 3·max(1, s³), 4·max(1, s³) | collapse = 1–3-voxel degeneracy; healthy m_v ≈ 45 s³ |

**Kept on purpose:** stage-04 `--min-ring-contrast −2` (binding: 130k rejections; a sign test with a 2-level = 0.8 %
tolerance on the robust range); `--support-contrast-norm 80`, `--delta-norm 20` (score normalisers in grey levels of
the robust range); `bg_ref` over blur ≥ 1 (one grey level, quantisation guard); all percentiles, ratios, weights,
τs = 0.35, overlap fractions, connectivities. The openrec floor 8 is the user's specification.
